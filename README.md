# CoordLogger

A client-side Minecraft Fabric mod that saves the player's last logout location.

## Features

* Saves coordinates and world information
* Stores the information in a .json file
* Displays the contents of the .json file ingame

## Requirements

* Minecraft 26.1.2
* Fabric Loader
* Fabric API
* Java 25

## Storage

The last logout location is saved to:

`config/coordlogger-last-location.json`

in the Minecraft instance's config directory.
